# BrandistiQ – finalna verzija za objavu

Ova verzija uključuje:
- portfolio s tri nova projekta i lokalno spremljene projektne fotografije
- uređenu Politiku privatnosti
- uređenu Politiku kolačića
- novu stranicu Pravne informacije

## Google Analytics

U `public/analytics-config.js` upišite svoj GA4 Measurement ID, npr. `G-XXXXXXXXXX`.

Analytics se učitava tek nakon prihvaćanja analitičkih kolačića. Ako je vrijednost prazna, Analytics se neće učitati.

## Važno prije objave

Provjerite da stvarna konfiguracija Google Analyticsa, Netlify Forms, hostinga i ostalih servisa odgovara tekstu Politike privatnosti i Politike kolačića. Ovaj paket nije zamjena za individualni pravni savjet.
